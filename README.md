## Linting and Formatting

This project uses ESLint and Prettier for code linting and formatting:

### Available Scripts

- `npm run lint` - Lint all files in the root
- `npm run lint:frontend` - Lint frontend files
- `npm run lint:backend` - Lint backend files
- `npm run lint:all` - Lint all files in the project
- `npm run format` - Format all files in the root
- `npm run format:frontend` - Format frontend files
- `npm run format:backend` - Format backend files
- `npm run format:all` - Format all files in the project

### VS Code Integration

VS Code is configured to automatically format files on save with ESLint and Prettier.

Recommended extensions are:

- ESLint
- Prettier
- GitHub Copilot
